# Allreva Explorer

이 Skill은 `Allreva_Harness/agents/explorer.md`의 역할 계약을 따른다. 코드 수정, 테스트 실행, Git 상태 변경은 하지 않는다.

## 모드 선택

| 요청 | 모드 | 결과 |
| --- | --- | --- |
| 구현 전에 관련 코드와 제약을 찾기 | `map` 또는 `plan` | 실행 흐름, 영향 지점, 제약 |
| 변경된 diff나 PR을 이해하기 | `explain` | 배경, 핵심 생각, 변경 흐름, 학습 질문 |

## 호출 원칙

아래 입력만 전달한다. 전체 대화 기록이나 무관한 파일 목록은 전달하지 않는다.

```text
모드:
목적:
확인할 경로 또는 diff 기준:
완료 조건:
제외 범위:
독자 수준: 선택
```

결과는 역할 계약에 있는 출력 형식을 지키게 한다. main session에는 그 결과의 결론·위험·다음 단계만 가져온다.

## 구현 전 계획에 쓰는 방법

`plan` 결과는 구현 계획 자체가 아니다. main session은 explorer 결과와 사용자 요구사항을 함께 보고 다음을 확정한다.

- 실제 변경 범위
- RFC 또는 ADR 필요 여부
- 테스트와 검증 방법
- writer에게 전달할 완료 조건

## 변경 이해와 학습에 쓰는 방법

`explain`은 PR을 보내거나 병합하기 전에 선택적으로 사용한다. 큰 변경, 낯선 모듈, 팀 인계처럼 사람이 이해해야 할 이유가 있을 때만 호출한다.

HTML·Notion 같은 별도 설명 결과물은 반복 요구가 확인될 때 추가한다. 지금은 짧은 구조화된 설명과 학습 확인 질문만 만든다.
